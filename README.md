### Hi, I'm JT

I build small Windows tools that fix problems I ran into myself: a PC that crashes at random, a disk full of
developer junk, a local AI model that won't stop when you press Stop, Blender renders that die overnight, and a
paycheck that doesn't add up after a long week. Everything runs on your own PC: no accounts, no tracking.

#### Free on GitHub

| Tool | What it does |
|---|---|
| [System Vitals](https://github.com/jtclone22-coder/SystemVitals) | PC health monitor and nightly backup for Windows 10 and 11 |
| [GPU Who](https://github.com/jtclone22-coder/GPUWho) | Which program is using which GPU, and how much VRAM (NVIDIA, Intel Arc, AMD) |
| [PathDoctor](https://github.com/jtclone22-coder/PathDoctor) | Windows PATH checkup: broken entries, and which program a command really runs |
| [RepoRadar](https://github.com/jtclone22-coder/RepoRadar) | Every git repo on your PC, and which ones hold work that exists nowhere else |
| [BackupProof](https://github.com/jtclone22-coder/BackupProof) | Proves a backup matches the originals: missing, outdated and corrupted files |
| [PortPilot](https://github.com/jtclone22-coder/PortPilot) | What's on which port, plus WSL, Docker and the hosts file |
| [ModelShelf](https://github.com/jtclone22-coder/ModelShelf) | See and tidy your local Ollama models |
| [Quarry](https://github.com/jtclone22-coder/Quarry) | Private code search for you and your AI agents, with an MCP server |
| [LogHarbor](https://github.com/jtclone22-coder/LogHarbor) | Your app logs and traces in one searchable local page |
| [llm-brake](https://github.com/jtclone22-coder/llm-brake) | A Stop button that actually stops your local LLM (Python library) |
